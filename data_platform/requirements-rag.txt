# Runtime dependencies for 05_rag_service.py (Dockerfile.rag).

# 05_rag_service.py is designed to degrade gracefully when these are
# missing (see its _ST_AVAILABLE / _PSYCOPG_AVAILABLE / _PROMETHEUS_AVAILABLE
# / _FASTAPI_AVAILABLE flags), but the container image installs all of them
# so the deployed service runs with full functionality, not fallbacks.
#
# feast is intentionally NOT included: FeatureLookup's local fallback
# computes the same trending/freshness formulas as 06_ml_platform.py's
# offline FeatureEngineer, and feast's dependency tree (pandas, pyarrow,
# dask, ...) is heavy and prone to version conflicts for the marginal
# benefit of an online-store lookup in this service.
