# AIDataBoon

AI-powered data infrastructure, in two layers that deploy independently:

| Folder | What it is | Live at |
|---|---|---|
| [`data_platform/`](data_platform/) | **AIDataBoon, the AI-Powered Data Infrastructure Platform**: ingestion (Hacker News, arXiv, GitHub trending), a Bronze/Silver/Gold lakehouse, a RAG search API, the ML platform (MLflow, Feast), observability and IaC | [aidataboon.com](https://aidataboon.com), `api.aidataboon.com/v1/search` |
| [`agents/`](agents/) | **AIDataBoon Agents, LLMOps and Multi-Agent Infrastructure**: prompt registry with A/B rollout, a RAG eval harness gated in CI, a multi-agent pipeline with episodic memory, guardrails and tracing | `agents.aidataboon.com` |

`agents/` builds on `data_platform/` (it calls the RAG API and includes the platform's Compose stack). Read each folder's `00_project_design.md` first.

`frontend/` holds the static search page. `feast_repo/` is generated by `data_platform/06_ml_platform.py` and git-ignored.

## Run it

```bash
uv sync

# Platform: full local stack (Postgres/pgvector, RAG API, Prometheus, Grafana, ...)
docker compose -f data_platform/01_local_stack.yml up -d

# Agents: includes the platform stack and adds the agent API on :8100
docker compose -f agents/01_agents_stack.yml up -d

# Eval gate (no services needed; uses the heuristic fallbacks)
uv run python agents/03_eval_harness.py
```

Pipelines can also run in CI: the `Data ingestion (R2)` workflow (`.github/workflows/ingest.yml`) needs the `S3_ENDPOINT_URL`, `S3_ACCESS_KEY` and `S3_SECRET_KEY` repository secrets. The agents CI/CD file lives in `agents/08_cicd_eval_pipeline.yml`; copy it to `.github/workflows/` to activate it.

## Deploy

Render Blueprints: `data_platform/render.yaml` (root directory `data_platform`) and `agents/render.yaml` (root directory `agents`). Cloudflare Terraform is separate per module (`data_platform/09_cloudflare_infra.tf`, `agents/07_cloudflare_agents.tf`), each with its own state. State files are git-ignored.
